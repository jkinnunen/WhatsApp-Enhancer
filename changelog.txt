## What's New?

### Version 1.1.4
* **Crash Fixes**: Migrated the background progress observer to the GUI thread and fixed speech patching memory leaks.
* **Optimized Context Menu (`shift+enter`)**: Replaced slow recursive searches with an instant single-pass traversal.
* **General Performance**: Accelerated voice message playback button.
* **Fix strict Browse Mode Lock**: Blocks `NVDA+space` keypresses entirely when locking is active to prevent accidental virtual buffer toggles.
